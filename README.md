# Módulo Front-End - Gestión de Inventario (Proyecto Formativo ADSO)

## 1. Descripción
Aplicación web desarrollada en React (Vite) para la gestión y control de inventarios de productos.

## 2. Relación con Historias de Usuario
* **HU-01:** Como usuario administrador, quiero registrar nuevos productos ingresando nombre, cantidad y precio mediante un formulario controlado.
* **HU-02:** Como usuario administrador, quiero visualizar el inventario en una tabla dinámica y poder eliminar registros obsoletos.
